# Additional Remotely Sync features

This directory contains additional remote-service implementations and sync
features. They are available to all users at no cost; no Remotely Sync account
or subscription is required.

## Included features

- Smart Conflict resolution.
- OneDrive full access, Google Drive, Box, pCloud, Yandex Disk, Koofr, and
  Azure Blob Storage integrations.

Configure each remote service in Remotely Sync settings and complete the
provider's authorization flow. Provider limits and fees, if any, still apply.

See the [feature guide](../docs/features/README.md) for user-facing details.
