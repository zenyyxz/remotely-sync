# Box

## Service and compatibility

Box's website is <https://www.box.com/>. This plugin is **not an official Box product**; it connects through Box's public API.

The plugin currently labels Box support **beta**. **Back up your vault before using it.**

## Connect and authorize

1. In Remotely Sync settings, select **Box** as the sync service.
2. Click **Auth** and open the link to start on Box's website.
3. Follow Box's instructions and allow Remotely Sync to connect.
4. You will be redirected back to the Remotely Sync plugin. A notice reports whether authorization succeeded.
5. Sync. The plugin creates a vault folder at the root of your Box and uploads notes there.

## Validate and troubleshoot

If authorization does not complete, confirm that you followed Box's authorization instructions and returned to the plugin. Check for the connection notice before syncing. Keep a backup of your vault, as this feature is beta.
