# Smart Conflict and additional services

These capabilities are included in Remotely Sync and do not require a separate
unlock or purchase.

## Included capabilities

- Smart Conflict resolution.
- Additional remote services: OneDrive (full access), Google Drive, Box,
  pCloud, Yandex Disk, Koofr, and Azure Blob Storage.

## Connecting a provider

Choose a service in Remotely Sync settings and follow its provider
authorization steps. The cloud provider's own usage limits and fees, if any,
continue to apply.
